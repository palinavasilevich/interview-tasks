# Дополнение строки пробелами слева (Left Pad)

## Problem

Напишите функцию leftPad, которая добавляет слева к строке пробелы. Функция принимает два аргумента: число, обозначающее минимальную длину результата, и строку, которую нужно дополнить, если её длина меньше.

Правила:

Если длина строки меньше указанной минимальной длины, добавляются пробелы слева

Если длина строки больше или равна указанной длине, строка возвращается без изменений

Функция должна возвращать новую строку, не изменяя исходную

## Examples

```
leftPad(6, 'test')    // -> "  test" (2 пробела слева)
leftPad(10, 'hello')  // -> "     hello" (5 пробелов)
leftPad(3, 'test')    // -> "test" (длина уже больше)
leftPad(0, 'abc')     // -> "abc"

```

## Constraints

- `Минимальная длина: 0 ≤ N ≤ 1000`

- `Длина строки: 0 ≤ length ≤ 1000`

- `Символы: любые`

- `Время выполнения: O(N)`

- `Память: O(N)`
