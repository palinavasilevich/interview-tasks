# Форматирование списка имён (Format Name List)

## Problem

Напишите функцию list, которая принимает массив объектов с полем name и возвращает строку, отформатированную в виде списка имён, разделённых запятыми, за исключением двух последних имён, которые должны быть разделены амперсандом &.

Правила:

Если массив пустой, вернуть пустую строку

Если в массиве один элемент, вернуть только это имя

Если в массиве два элемента, вернуть "name1 & name2"

Если в массиве три и более элементов, все имена, кроме последних двух, разделяются запятыми, а последние два — амперсандом

## Examples

```
list([{name:'Bart'}])                      // -> "Bart"
list([{name:'Bart'}, {name: 'Lisa'}])      // -> "Bart & Lisa"
list([{name:'Bart'}, {name: 'Lisa'}, {name: 'Maggie'}])  // -> "Bart, Lisa & Maggie"
list([])

```

## Constraints

- `Длина массива: 0 ≤ N ≤ 1000`

- `Объекты всегда имеют поле name`

- `Имена — строки`

- `Время выполнения: O(N)`

- `Память: O(N)`
