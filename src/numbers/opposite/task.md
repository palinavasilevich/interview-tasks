# Opposite Number

## Problem

Given a number, return its opposite (negated value).

## Examples

```ts
opposite(1);    // -1
opposite(-1);   // 1
opposite(0);    // 0 (or -0, both are equal in JS)
opposite(3.14); // -3.14
```

## Constraints

- Input can be any number: positive, negative, integer, or float

## Notes

- Unary `-` is all you need — no `Math.abs` or conditionals required
